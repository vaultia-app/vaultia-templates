## [0.1.0] - 2026-11-28

### Added
- Product requirements documentation starter kit, including NFR categories and an SLA table.
- Base UI React kit with Tailwind CSS v4, design tokens, generated themes, and English and Vietnamese locales.
- Manifest validation and React kit typecheck and theme checks.
- Tag-driven release workflow with individual and combined template archives and SHA-256 checksums.

### Changed
- Base UI React kit uses the shadcn/ui Neutral palette.
