## Checklist

Every screen meets these before it is Approved. Exceptions are listed below with a decision ID.

| Area | Requirement |
|---|---|
| Contrast | Text 4.5:1, large text and UI components 3:1, in light and dark themes |
| Keyboard | Every action reachable and operable by keyboard; visible focus; logical tab order; no keyboard traps |
| Screen readers | Meaningful labels for controls, icons, and images; headings in order; live regions for async messages |
| Forms | Visible labels; errors described in text and linked to their field; required fields marked |
| Motion | Respect reduced-motion settings; nothing flashes more than 3 times per second |
| Touch | Targets at least 44 × 44 px with spacing |
| Zoom and reflow | Usable at 200% zoom and 320 px width without horizontal scrolling |
| Color | Color is never the only way information is conveyed |
| Time | Time limits can be extended or turned off |
